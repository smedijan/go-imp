# Why imp exists

`imp` continues the mutation-testing work originally published as
[go-gremlins/gremlins](https://github.com/go-gremlins/gremlins).

The original project had been inactive for many months, and its maintainer was not reachable. Rather than let useful
mutation-testing tooling stagnate, Smedijan is maintaining this independent continuation.

Mutation testing is increasingly valuable as coding agents generate more code. `imp` aims to help agents and developers
produce code that is easier to test, and test suites that catch more behavioral regressions. This fork is the start of
that work; its scope and direction may evolve as Smedijan develops it.
